# 01 — How to Start

First-build samples. Use these to verify your Zephyr workspace, SDK, and
board are wired up correctly before moving on.

## Planned samples

| Sample | Source page | What it shows |
|---|---|---|
| `hello_world/` | `zephyr-training/01_how-to-start/hello-world.md` | Smallest possible Zephyr app — prints `Hello World! <board>` over UART |

## Prerequisites

- A working `west` workspace
- Zephyr SDK installed and `ZEPHYR_BASE` resolvable (west sets this automatically)
- Serial monitor at **115200 baud**
